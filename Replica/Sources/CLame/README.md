# LAME encoder

Source: https://github.com/lameproject/lame/tree/1f5cc9487284d5950343aa5d4f70de433468070a

LAME 3.100 encoder sources, unchanged. Decoder, frontend and assembly are excluded. The generated config.h targets 64-bit Apple platforms. Built as a separate Swift Package C target. See COPYING and LICENSE. Retain this source and the application link inputs for LGPL relinking when distributing binaries.
