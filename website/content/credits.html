Audio, analysis and type.

GenErik DJ includes open-source components and model assets. These acknowledgements describe the audited development source. Inclusion does not establish that every experimental feature is release-approved.

Application components

  • Signalsmith Stretch and Signalsmith Linear.
  • Beat This! rhythm-analysis models.
  • MusicalKeyCNN and librosa-derived filter coefficients.
  • whisper.cpp and Whisper model assets.
  • Hybrid Transformer Demucs and bundled stem-model assets.
