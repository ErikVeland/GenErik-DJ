Accessibility support and known limits.

Website

The site uses semantic headings, labelled navigation, a skip link, visible keyboard focus and native links and disclosure controls. Product images have text alternatives. Content and navigation do not depend on JavaScript.

The layout adapts to narrow screens and enlarged text. Motion is limited to optional focus and interaction feedback. Reduced-motion preferences disable smooth scrolling.

These implementation choices are not a claim of WCAG certification. The verification record is maintained with the website source.

GenErik DJ app

The development app contains accessibility labels and actions for some controls, including track loading. A complete VoiceOver, Dynamic Type, Switch Control and keyboard workflow has not been verified.

No full accessibility conformance claim is made for the app. The iPad performance interface is still under test.
