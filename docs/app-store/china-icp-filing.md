## Official filing route

MIIT directs an app sponsor to file with the communications administration for the sponsor's place of residence. A network access provider or app distribution platform submits the application through the national filing system. The provider checks the sponsor's identity and network resources. An individual can be an app sponsor, but the published rule does not establish whether an Australian-resident individual can use this route.
